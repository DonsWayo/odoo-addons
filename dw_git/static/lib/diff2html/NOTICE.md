# diff2html

Vendored from https://github.com/rtfpessoa/diff2html (v3.4.51), MIT License.
Pre-built UMD bundles, used as-is: `diff2html-ui-slim.min.js` + `diff2html.min.css`.
Renders the unified diff text stored on `git.pr.file.patch` as a colored,
side-by-side diff with syntax highlighting. No build step, no bundler.
